# Ten-Inch Rack Agent Spec Bundle

Files:

- `10-inch-rack-agent-readable-design-spec.md` — expanded human- and agent-readable report.
- `10-inch-rack-parameters.json` — canonical machine-readable parameters and rules.
- `rack_constants_and_assertions.scad` — reusable OpenSCAD constants, depth resolution, and assertion helpers.

The Markdown report is authoritative for semantics. The JSON and SCAD files are companions and should remain synchronized with the report version.
