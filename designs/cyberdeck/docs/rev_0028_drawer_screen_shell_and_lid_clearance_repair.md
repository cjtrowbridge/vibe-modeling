  row for both the battery and Meshtastic drawers.

  matching removable drawer backplate.
- Kept the failed projecting nut bosses, nut traps, and standoffs removed.
- Reserved the full larger of the M3 head and nut envelopes, rather than sizing
  only around the `3.4 mm` through-hole.
- Restored the screen mounting columns to the screen-derived symmetric
  `x = +/-115 mm` datum.

  column remains at `x = +136.5 mm`.
- Made both compact exterior side boundaries coincide with the display profile
  shell boundaries. Each compact chamber side is now generated by one continuous
  profile shell instead of a narrow flat/profile transition strip.
- Retained a named `3.0 mm` overlap for any non-compact flat/profile transition.
- Lowered the divider to a derived lid-envelope limit with a full `3.0 mm`
  clearance below the lid's swept lower envelope.
